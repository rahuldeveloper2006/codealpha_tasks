# 📊 Unemployment Analysis in India

## 📌 Project Overview

This project analyzes unemployment trends in India using Python and Exploratory Data Analysis (EDA). The objective is to understand unemployment patterns across different regions, identify the impact of COVID-19, and generate meaningful insights using data visualization.

---

## 📂 Dataset

- Dataset: Unemployment in India
- Records: 768
- Features:
  - Region
  - Date
  - Frequency
  - Estimated Unemployment Rate (%)
  - Estimated Employed
  - Estimated Labour Participation Rate (%)
  - Area

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Exploratory Data Analysis (EDA)

The following analyses were performed:

- Data Cleaning
- Missing Value Handling
- Overall Unemployment Statistics
- Region with Highest Unemployment Rate
- Region with Lowest Unemployment Rate
- Top 10 Regions by Average Unemployment Rate
- Area-wise Unemployment Analysis
- Monthly Unemployment Trend
- COVID-19 Impact Analysis
- Correlation Heatmap
- Distribution Analysis

---

## 📊 Key Insights

- Calculated the overall unemployment rate.
- Compared unemployment across different regions.
- Analyzed Urban and Rural unemployment.
- Studied monthly unemployment trends.
- Investigated the impact of COVID-19.
- Identified relationships between numerical variables using a correlation heatmap.
